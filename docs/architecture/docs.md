# Docs

`docs/` 아래 모든 문서의 작성 규칙.

## 1. 어미

- 서술은 `~함` / `~임` / `~없음`의 명사형 종결로 씀.
- `~한다` / `~했다` / `~해라` / `~해요` 같은 문장형 어미를 쓰지 않음.
- 표의 셀과 목록 항목은 명사구로 끝내도 됨.

## 2. 표현

- 의도를 남기는 데 필요한 표현만 남김.
- 다른 표현으로 대체되거나 없어도 의도가 남는 문장은 지움 — 도입부 인사, 같은 말의
  재진술, 문서 자신에 대한 설명.
- 근거는 그 판단이 실제로 갈리는 지점에만 씀. 규칙만으로 충분하면 근거를 붙이지 않음.
- 예시는 규칙만으로 형태가 특정되지 않을 때만 넣고, 최소 크기로 씀.

## 3. 책임

- **각 문서의 책임은 고유해야 하며, 다른 문서와 중복되는 내용을 다루어서는 안 됨.**
- 한 내용은 책임이 가장 명확한 문서 하나에만 씀. 다른 문서에서 필요하면 링크와 절 번호로
  가리킴.
- 요약도 중복임. 다른 문서의 규칙을 옮겨 적는 대신 그 문서를 가리킴.
- 어느 문서가 소유해야 할지 갈리면 그 내용을 쓰는 쪽이 아니라 그 내용을 **정의하는** 쪽이
  가짐.

## 4. 절 번호

절 번호는 다른 문서·스킬·워크플로우가 참조하는 주소임. 내용을 지우거나 옮길 때 남은 절의
번호를 바꾸지 않음. 참조가 깨지면 참조하는 쪽도 함께 고침.
